# EZBuild Website

EZBuild 官网项目。

## 技术栈

- **React** + **TypeScript** — 前端框架与类型系统
- **Vite** — 构建工具
- **Redux Toolkit** — 状态管理
- **MUI** + **Ant Design** — UI 组件库

## 开发环境要求

- [Node.js](https://nodejs.org/)
- [pnpm](https://pnpm.io/)

## 快速开始

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 代码格式化

```bash
pnpm format
```
